ミャンマー文字の記号はどこに付く?

2026-11-09

まずは、この単語を見てください。

ကျောင်း

「学校」という意味の言葉です。丸い文字の周りに、小さな記号がいくつも付いています。

では、どこから読めばいいのでしょう？一番左にある記号から……と思いたくなりますが、実はそこから読み始めるのではありません。

ミャンマー文字の記号は、子音の上にも下にも、右にも左にも付きます。今回は、どの記号がどこに付くのかを図で整理して、文字を1つずつ足しながら動きを観察してみました。

1. 真ん中にいるのは子音

ミャンマー文字は、クメール文字やタイ文字と同じく、インド系の文字の仲間です。子音の文字が中心にあって、その周りに母音の記号が付きます。

何も付いていない က は、それだけで「カ」に近い音を表します。別の母音にしたいときに、記号を足します。

配置を1枚の図にしてみました。

実際に က に付けると、こうなります。

形記号の場所読み(IPA)
ကေ左kè
ကိ上kḭ
ကီ上kì
ကဲ上kɛ́
ကု下kṵ
ကူ下kù
ကာ右kà
ကော左と右kɔ́
ကို上と下kò

面白いのは最後の2つです。ော は ေ と ာ の組み合わせで、子音を左右からはさみます。ို は ိ と ု の組み合わせで、上下からはさみます。1つの母音が、2か所に分かれて書かれるんですね。

もう1つ、右に付く ာ には、背の高い ါ という形もあります。音は同じで、ခ や ပ など、一部の子音の後ろで使われます。また、下に付く ု や ူ は、下の場所がふさがっていると少し右にずれることがあります。記号の位置は、周りの文字に合わせて微調整されているわけです。

2. 子音にくっつく「介子音」

ミャンマー文字には、母音の記号とは別に、子音に音を足す4つの記号があります。介子音と呼ばれるものです。

ျ と ြ は形も位置もまるで違うのに、標準的なミャンマー語では同じ音になります。ラカイン語(アラカン語)のような方言では、ြ を r の音で読むそうです。つづりに古い音の区別が残っている、というわけですね。

さらに、က のような子音に付くと音そのものが変わります。ကျ も ကြ も、「キャ」ではなく「チャ」に近い音 [tɕ] になります。

特に見た目で迷うのが ြ です。子音の左側から上下にまで回り込むので、左端に大きなカッコのような線があったら、たいていこれです。

3. 「学校」を分解してみる

ここまでの知識で、最初の単語に戻ってみましょう。

左端の ေ は、一番左に書かれていますが、読む順番では子音の後ろです。「左にあるけれど、音は後」。ここが最初のつまずきポイントだと思います。

ちなみに、この ကျောင်း は「学校」だけでなく「僧院」も意味します。ミャンマーでは、僧院が村の子どもたちの教育の場でもあったそうです。古いビルマ語では က္လောင်း(klong)という形だったといわれ、今の「チャ」の音になる前の姿がしのばれます。一つの単語から、文化の話まで広がっていくのが楽しいですね。

4. 見た目の順と、データの順

ここからは寄り道です。調べていて一番驚いたのがこの話でした。

パソコンやスマホの中では、文字は1列に並んだデータとして保存されています。では、一番左に見える ေ は、データでも先頭にあるのでしょうか？

正解は、子音の後ろでした。Unicode では ေ は発音の順番どおり、子音や介子音の後ろに入ります。左に表示するのは、フォントと表示の仕組みの仕事です。

実際に体験してみましょう。ボタンを押すと、データの順番どおりに部品を1つずつ足していきます。

データに入っている順

ေ を足した瞬間に、記号が子音の左へ移動しましたか？データでは後ろに足しているのに、画面では前に出るわけです。

ただし、これは「保存される順番」の話です。キーボードによっては、ေ を子音より先に打てるようになっているものもあるそうです。紙に書く感覚に合わせた工夫ですね。

タイ文字は逆だった

同じインド系の文字でも、この扱いは文字によって違います。比べてみました。

文字形データの順
ミャンマー文字ကေက → ◌ေ
クメール文字កេក → ◌េ
タイ文字เกเ → ก

タイ文字では、左に書く母音は、データでも子音の前に入ります。発音の順番ではなく、見た目の順番です。見た目はよく似た仕組みなのに、コンピューターの中での扱いは正反対なんですね。

ミャンマーで起きた「文字コード問題」

実はミャンマーでは、この順番の違いが社会全体の問題になっていました。

2006年ごろに作られた Zawgyi(ゾージー)というフォントと入力方式は、紙に書く見た目の順番で打てるのが特徴でした。分かりやすさもあって、Unicode よりも広く普及したそうです。ところが Zawgyi は Unicode の規格に沿っていなかったため、片方の方式で書いた文章が、もう片方では文字化けしてしまいます。同じ単語にいくつもの打ち方が存在して、検索や並べ替えも難しかったといわれています。

そこでミャンマー政府は、2019年10月1日を「U-Day」と定めて、Unicode への公式な移行を進めました。記号が子音のどちら側にあるか、という小さな話が、国全体のデジタル環境を左右していたわけです。

5. 読むときのコツをまとめると

  • まず、音節の中心になる子音を探す
  • 左端の ေ や ြ から読み始めない。ြ は子音とセットで読む
  • 次に、母音の記号を上下左右から集める
  • ် が付いた文字は、音節の終わりの音
  • 最後に း などの声調の記号を確認する

文字の周りの記号は、最初は飾りのかたまりに見えます。でも場所ごとの役割が分かると、1つの音節がブロックのように見えてきました。

単語をもっと分解してみたい方は、ミャンマー語の単語分解ツールも試してみてください。部品ごとにタップして、役割を確認できます。
